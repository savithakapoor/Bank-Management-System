# Bank Management System

A console-based Bank Management Application developed in C++ using Object-Oriented Programming and File Handling concepts.

## Features

- Create New Bank Account
- Deposit Money
- Withdraw Money
- Check Account Balance
- Display All Accounts
- Persistent Data Storage using File Handling

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling
- Console Application

## Concepts Implemented

- Classes and Objects
- Encapsulation
- Functions
- File Handling using fstream
- Menu-Driven Programming

## Project Description

This project simulates basic banking operations such as account creation, deposits, withdrawals, and balance inquiries. Customer data is stored securely in files for persistent record management.

## How to Run

1. Open the project in any C++ IDE (Code::Blocks / Dev C++ / VS Code).
2. Compile the program.
3. Run the executable file.
4. Use the menu options to perform banking operations.
